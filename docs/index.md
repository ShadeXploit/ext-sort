# ext-sort

Organize recovered files — or any messy folder of mixed files — into a cleaner structure.

## Why this project exists

Recovered data is usually not tidy. Files often come back with random names, mixed formats, and no useful organization. `ext-sort` is meant to make that output easier to inspect by grouping files into logical folders based on extension or type.

## Good fits for ext-sort

- recovered storage data
- memory card and USB recovery results
- download folder cleanup
- backup triage
- large mixed file collections

## What it helps with

- separating media from documents and archives
- making recovered data easier to browse
- reducing manual sorting work
- creating a cleaner review workflow

## Example result

```text
recovered/  ->  sorted/

.jpg files  ->  jpg/
.mp4 files  ->  mp4/
.pdf files  ->  pdf/
.zip files  ->  zip/
no extension -> unknown/
```
